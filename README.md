# RAXIS Homebrew Tap

This repository is the Homebrew tap for RAXIS. It is intentionally tiny:
release automation from `chika5105/raxis` writes `Formula/raxis.rb`
after each tagged release.

```bash
brew tap chika5105/raxis
brew install raxis
```

The tap repository name follows Homebrew convention:
`chika5105/homebrew-raxis` maps to the user-facing tap name
`chika5105/raxis`.
